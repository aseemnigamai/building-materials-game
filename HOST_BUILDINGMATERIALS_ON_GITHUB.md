# 🏗️ HOW TO HOST BUILDING MATERIALS GAME ON GITHUB

## ⏱️ TIME: 5-10 MINUTES

---

## 📋 WHAT YOU NEED

✅ File: `BuildingMaterialsGame.html` (you have this!)
✅ GitHub Account (free)
✅ Browser (Chrome, Firefox, Safari)
✅ Internet connection

---

## 🔴 STEP 1: CREATE GITHUB ACCOUNT (Skip if you have one)

### **Go to github.com and sign up:**

1. Visit **github.com**
2. Click **"Sign up"** button (top right)
3. Enter your **email address**
4. Create a **password**
5. Choose a **username** ⭐ (Important! You'll use this in the URL)
   - Example: john-doe, jane-smith, myname123
6. Complete **email verification**

**Your account is ready!** ✅

---

## 🟠 STEP 2: CREATE A NEW REPOSITORY

### **What is a repository?**
It's a folder on GitHub that stores your game file.

### **How to create:**

1. After login, click the **"+" icon** (top right corner)
2. Select **"New repository"**

   OR go directly to: **github.com/new**

3. **Fill in the form:**

```
Repository name:      building-materials-game
(IMPORTANT: use lowercase, use hyphens)

Description:          Building Materials Business Game
(optional but good)

Visibility:           ⭐ PUBLIC (MUST be PUBLIC!)
(If private, others can't access it)
```

4. Click **"Create repository"** button

**Your repository is created!** ✅

---

## 🟡 STEP 3: UPLOAD THE GAME FILE

### **You should see a page with "quick setup" message**

1. Click **"Add file"** button (top center)
2. Select **"Upload files"**

OR

Click the area that says **"uploading an existing file"**

### **Upload the file:**

1. Click in the **upload box** OR drag and drop
2. Select file: **BuildingMaterialsGame.html** from your computer
3. Wait for upload to complete (progress bar)
4. Scroll down and click **"Commit changes"** button

**Game file uploaded!** ✅

---

## 🟢 STEP 4: ENABLE GITHUB PAGES (MAKE IT LIVE)

### **This is the IMPORTANT step that makes it playable!**

1. At the **top of repository**, find these tabs:
   ```
   Code  |  Issues  |  Pull requests  |  Settings
   ```

2. Click **"Settings"** tab

3. On **left sidebar**, scroll down to find **"Pages"**

4. Click **"Pages"**

5. You'll see **"Build and deployment"** section

6. Find the dropdown that says **"None"**
   - Click it
   - Select **"main"** (the main branch)
   - Click **"Save"** button

7. **Wait 1-3 minutes** ⏳

You'll see a **blue/green message** that says:
```
✓ Your site is live at:
https://[your-username].github.io/building-materials-game/
```

**GitHub Pages is now ENABLED!** ✅

## 🟣 STEP 6: TEST YOUR GAME

### **Verify the game works:**

1. **Open a new browser tab**
2. **Paste your URL** from Step 5
3. **Press Enter**
4. **Game should load!** ✅

You should see:
```
🏗️ Building Materials Game

Login Screen
├─ Your Business Name (text box)
├─ Password (text box)
└─ LOGIN button
```

### **If game doesn't load:**
- ⏳ Wait 3-5 more minutes (first time takes longer)
- 🔄 Refresh the page (Ctrl+F5 or Cmd+Shift+R)
- 🗑️ Clear browser cache (Ctrl+Shift+Delete)
- 🌐 Try different browser

## 💡 TROUBLESHOOTING

### **"URL doesn't work / 404 Error"**
```
✅ Wait 3-5 minutes (takes time to activate)
✅ Refresh page (Ctrl+F5)
✅ Clear cache (Ctrl+Shift+Delete)
✅ Try different browser (Chrome, Firefox)
✅ Check repository is PUBLIC (not private)
✅ Check filename is exactly: BuildingMaterialsGame.html
```

### **"Game page shows code instead of game"**
```
✅ Clear cache and refresh
✅ Try Ctrl+F5 (hard refresh)
✅ Try incognito/private window
✅ Check JavaScript is enabled in browser
```

### **"Can't login as admin"**
```
✅ Username: admin (exact, lowercase)
✅ Password: admin123 (exact, no spaces)
✅ Make sure you copied it correctly
```

### **"Can't login as participant"**
```
✅ Just enter your business name
✅ Leave password BLANK (empty)
✅ Click LOGIN
```

### **"Repository not created"**
```
Error: "Owner is being deleted"
✅ Create NEW GitHub account with different email
✅ Try again with new account
```
